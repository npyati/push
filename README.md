# push

A simple, single-file fitness timer and workout tracker for circuit training.

## Features

- **Circuit & Sequential Modes** - Train all exercises per round, or complete all rounds of one exercise
- **Rep & Time-based Exercises** - Track both repetition targets and timed intervals
- **Side-specific Training** - Built-in support for unilateral exercises (left/right)
- **Timer Controls** - Auto-advance timer with keyboard shortcuts
- **Workout Management** - Save and load custom workout plans
- **Keyboard Shortcuts**
  - `Space` - Start/pause timer
  - `Enter` - Complete reps
  - `R` - Reset
  - `←` `→` - Navigate exercises

## Usage

Simply open `index.html` in your browser. No build process or dependencies required.

## Tech Stack

Pure HTML, CSS, and JavaScript - runs entirely in the browser.
